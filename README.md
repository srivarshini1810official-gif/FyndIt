# FyndIt – Online Shopping Website

FyndIt is an e-commerce website developed using HTML, CSS, JavaScript, jQuery, AJAX and Firebase REST APIs.

## Features

- Customer registration and login
- Admin login and dashboard
- Product browsing and search
- Eight product categories with 64 products
- Shopping cart and checkout
- Order confirmation and order history
- Product and customer management
- Order management and sales dashboard

## Technology Stack

- HTML5
- CSS3
- JavaScript
- jQuery
- AJAX
- Firebase Authentication REST API
- Cloud Firestore REST API
- Git and GitHub

## Project Structure

The project contains separate HTML, CSS and JavaScript files for customer pages, product pages, cart, checkout and admin management.
